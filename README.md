# StudyTok (스터디톡)

> 지루한 텍스트 학습 자료를 **AI가 숏폼 카드와 즉석 퀴즈로 바꿔 주는** 세로 스크롤 마이크로 러닝 웹앱

서울시립대학교 경영학부 · AI실무활용과스마트비즈니스 (2026-2) 기말 팀 프로젝트

## 1. 한 줄 요약

**누구의** 대학생·수험생이 **어떤 순간에** 시험 기간 텍스트 위주 강의자료를 읽다가 집중이 끊길 때,
**무엇으로** 자료를 올리면 AI가 핵심을 쪼개 릴스·틱톡처럼 넘겨 보는 숏폼 카드와 즉석 퀴즈로 만들어 준다.

## 4. 문제와 해결

- **차별화 트랙**: B(진짜 이야기, 팀원 경험) 중심에 A(진짜 데이터)로 보강

- **문제**: 텍스트 중심 학습 자료는 길고 지루해서, 숏폼에 익숙한 대학생·수험생의 집중이 쉽게 끊긴다.
- **해결**: AI가 학습 자료를 구조화해 한 화면 한 개념의 숏폼 카드로 만들고, 카드 사이사이에 바로 답하는 퀴즈를 넣는다. 세로 스크롤, 모션, 사운드, 즉각 피드백으로 "한 장만 더" 넘기게 만드는 숏폼의 습관을 학습 쪽으로 돌린다.
- **핵심 기능**: PDF 업로드 → 페이지 범위 선택 → AI가 카드·퀴즈 생성 → 세로 스크롤 피드에서 학습·퀴즈 풀이

### 지금 동작하는 기능

| 기능 | 설명 |
|---|---|
| PDF 업로드 + 페이지 범위 선택 | 브라우저에서 PDF를 읽어 쪽수를 보여 주고, 몇 쪽부터 몇 쪽까지 만들지 고른다 (한 번에 최대 30쪽). 파일은 서버에 저장하지 않는다. |
| 형식 선택 | **텍스트 숏츠(기본)**: 짧은 글 + 코드로 그린 도표·그래프(막대, 원, 흐름, 순환, 비교, 핵심어, 공식, 연표). **모션그래픽(추가 옵션)**: 핵심어가 차례로 터지는 애니메이션, 움직이는 도표, 음성 내레이션. 출력이 더 길어 비용이 더 든다. |
| 숏폼 피드 | 한 화면 한 개념, 위로 넘기는 세로 스크롤. 3장씩 나눠 만들어 첫 카드가 오면 바로 보기 시작한다. |
| 즉석 퀴즈 | 개념 2~3장마다 4지선다. 정답이면 효과음·진동, **오답이어도 다음으로 넘어가되 바로 뒤에 해설 카드를 끼워 넣는다.** 건너뛰기도 가능. |
| 샘플 덱 | AI 호출 없이 바로 체험하는 시연용 덱 (텍스트·모션 둘 다). |
| 모델 비교 실험실 (`/lab`) | 같은 자료를 Opus 5.5 · Sonnet 5.5 · Haiku 5.5 로 동시에 만들어 카드, 시간, 비용을 나란히 비교한다. |

## 6. 데이터: 실제인가, 가상인가

| 데이터 | 실제 / 가상 | 출처 · 비고 |
|---|---|---|
| 샘플 덱 '수요와 공급, 60초 컷' | 가상 (시연용) | 경제학원론 기초 개념을 정리한 예시. 막대그래프 숫자는 화면에도 '가상 예시'로 표시 |
| AI 생성 카드·퀴즈 | 실제 생성 결과 | 사용한 AI 모델 명시 |
| 사용자 반응·통계 화면 | _기재 예정_ | 가상이면 화면에도 **'가상'** 표시 |
| 인터뷰·설문 | _기재 예정_ | 원문/요약 링크 |

> 목업 데이터·가상 고객·시뮬레이션은 화면과 이 표에 '가상'이라고 표시합니다. 출처 없는 숫자는 쓰지 않습니다.

## 9. 기술 구성

- **프론트엔드**: Next.js 15 (App Router) + React 19 + TypeScript, CSS만으로 모션 처리
- **PDF 처리**: 브라우저에서 pdf.js 로 글자 추출. 글자가 거의 없는 스캔 페이지만 pdf-lib 로 그 쪽만 잘라 AI에 보냄
- **AI**: Anthropic Claude API (`/api/generate` 서버 함수). 구조화 출력(JSON 스키마)으로 카드 형식 고정, 거절 시 서버측 대체 모델(fallback) 사용
- **소리·음성**: Web Audio 효과음 합성, Web Speech API 내레이션 (추가 비용 없음)
- **배포**: Vercel (Hobby)

```
app/page.tsx            시작 화면 ↔ 피드 전환, 조각별 생성 순서 제어, 결과 캐시
app/lab/page.tsx        모델 비교 실험실
app/api/generate/       Claude 호출 서버 함수 (키·한도·입력 상한 검사)
components/             Setup(업로드·범위·형식·모델), Feed(세로 피드·퀴즈·해설 삽입), CardView, Visual(코드로 그린 도식)
lib/prompt.ts           시스템 프롬프트와 JSON 스키마
lib/pdf.ts              PDF 읽기·페이지 묶기
data/sampleDeck.ts      시연용 샘플 덱
scripts/compare-models.mjs  세 모델 × 두 형식 비교 결과를 표로 저장
```

**비용·안정성 원칙 (비용 관리 스레드에서 정함)**

- AI는 서버 함수에서만 호출하고, API 키는 Vercel 환경변수에만 둔다.
- 생성 결과는 브라우저에 저장해서 같은 자료·범위·형식·모델이면 다시 쓰고, 시연용 기본 덱은 미리 만들어 정적 JSON으로 둔다 (API 장애 대비).
- DB 없이 시작하고, 로그인·공유가 필요해지면 Supabase Free를 쓴다.
- Vercel Hobby 함수 60초 제한에 맞춰 입력 길이 상한과 스트리밍을 둔다.
- IP당 하루 생성 횟수와 max_tokens에 상한을 둔다.
- 모션·사운드는 CSS/Lottie와 Web Speech API로 처리하고, 이미지·음성 생성 API는 쓰지 않는다.

### 로컬 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                  # http://localhost:3000
npm run compare              # (선택) dev 서버를 띄운 상태에서 모델 비교 실행
```

키가 없어도 샘플 덱은 동작합니다. Vercel 에서는 프로젝트 설정 > Environment Variables 에 `ANTHROPIC_API_KEY` 를 넣습니다.
