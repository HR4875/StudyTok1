# StudyTok (스터디톡)

> 지루한 텍스트 학습 자료를 **AI가 숏폼 카드와 즉석 퀴즈로 바꿔 주는** 세로 스크롤 마이크로 러닝 웹앱

서울시립대학교 경영학부 · AI실무활용과스마트비즈니스 (2026-2) 기말 팀 프로젝트

---

## 1. 한 줄 요약

**누구의** 대학생·수험생이 **어떤 순간에** 시험 기간 텍스트 위주 강의자료를 읽다가 집중이 끊길 때,
**무엇으로** 자료를 올리면 AI가 핵심을 쪼개 릴스·틱톡처럼 넘겨 보는 숏폼 카드와 즉석 퀴즈로 만들어 준다.

## 4. 문제와 해결

- **차별화 트랙**: B(진짜 이야기, 팀원 경험) 중심에 A(진짜 데이터)로 보강

- **문제**: 텍스트 중심 학습 자료는 길고 지루해서, 숏폼에 익숙한 대학생·수험생의 집중이 쉽게 끊긴다.
- **해결**: AI가 학습 자료를 구조화해 한 화면 한 개념의 숏폼 카드로 만들고, 카드 사이사이에 바로 답하는 퀴즈를 넣는다. 세로 스크롤, 모션, 사운드, 즉각 피드백으로 "한 장만 더" 넘기게 만드는 숏폼의 습관을 학습 쪽으로 돌린다.
- **핵심 기능**: PDF 업로드 → 페이지 범위 선택 → AI가 카드·퀴즈 생성 → 세로 스크롤 피드에서 학습·퀴즈 풀이

### 지금 동작하는 기능

| 기능 | 설명 |
|---|---|
| PDF·사진 업로드 + 쪽 범위 선택 | PDF는 늘 쪽 범위 화면이 먼저 뜬다. 쪽 미리보기를 두 번 눌러(시작 쪽 → 끝 쪽) 범위를 고르거나 추천·전체·다음 묶음을 고른다. 글자 예산 막대(한 번에 3만 자)와 예상 시간이 함께 보인다. 글자 PDF에서 글자가 거의 없는 쪽(그림 위주 슬라이드)은 그 쪽만 그림으로 읽고, 글자가 없는 스캔본은 쪽을 그림으로 보낸다 (한 번에 8쪽). 강의 사진도 올릴 수 있다. 파일은 서버에 저장하지 않는다. |
| 보는 방식 선택 | **텍스트 숏츠(기본)**: AI가 개념마다 가장 잘 맞는 그림 틀을 고르고(단계·연쇄·순환·분류·비교·주고받기·그래프·비율·2축 지도·공식·연표·비유 12종) 칸만 채우면, 그림은 코드가 그린다. **모션그래픽(옵션)**: 같은 카드를 궁금증 질문 → 그림이 하나씩 등장 → 강조 → 개념 이름 순서의 짧은 영상으로 보여 준다. 코드가 만드는 움직임이라 AI를 더 부르지 않고, 피드에서 언제든 바꿀 수 있다. |
| 개념별 그림 판단 | 개념을 뽑을 때 "이 개념은 어떤 그림이 제일 잘 보이나"를 같이 정한다. 코드가 한 번 더 걸러서, 원문에 숫자가 없는데 그래프를 고르면 다른 틀로 바꾸고, 같은 틀이 세 번 이어지면 셋째를 다음 후보로 바꾼다. |
| 자동 검사·재시도 | AI 결과를 코드가 검사한다. 문제가 있으면 무엇이 틀렸는지와 이전 답을 붙여 한 번만 다시 받고, 그래도 안 되면 AI 없이 기본 텍스트 카드로 채운다. 카드 한 장이 실패해도 덱은 끝까지 만들어진다. |
| 숏폼 피드 | 한 화면 한 개념, 세로로 넘긴다. 개념을 찾는 동안 찾은 개념과 고른 그림 틀이 바로 보이고, 카드는 2장씩 동시에 만들어 준비된 카드부터 보기 시작한다. 텍스트/모션 보기, 재생 속도, 반복/자동 넘김, 자막, 효과음을 고를 수 있다. 이웃한 카드는 배경색이 겹치지 않는다. |
| 즉석 퀴즈 · 오답노트 | 개념 몇 장마다(기본 3장) 4지선다 퀴즈. 고르면 바로 정답·해설과 효과음. 틀린 문제는 오답노트에 담고 3장 뒤에 다시 낸다. |
| 내 자료 보관함 | 만든 덱은 브라우저에 저장된다. 같은 파일·쪽 범위·개념 수면 다시 만들지 않고 저장된 덱을 연다. |
| 예시 덱 | AI 호출 없이 바로 체험하는 덱 2개. ① 마케팅 전략의 기초: 시험용 강의 자료로 실제 생성한 텍스트 숏츠 5장 (모션 보기 가능) ② 맛보기 4과목: 처음 시안의 모션 예시 (API · 광합성 · FOB · 수요 법칙). |

## 9. 기술 구성

- **프론트엔드**: Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS 4
- **그림·모션**: 그림 틀 12종을 코드로 그린다. 텍스트 숏츠는 CSS 등장 효과, 모션은 같은 카드로 시간표를 만들어 Remotion Player 로 브라우저에서 재생한다. 영상 파일은 만들지 않는다.
- **폰트**: Pretendard(본문), Jua(큰 제목). 둘 다 npm 패키지로 직접 포함
- **PDF 처리**: 브라우저에서 pdf.js 로 글자를 뽑는다 (글자 위치로 띄어쓰기를 되살림). 쪽 미리보기도 브라우저에서 그린다. 전체 글자가 max(40, 쪽수×8)보다 적으면 스캔본으로 보고 쪽을 JPEG 로, 글자 PDF에서는 글자가 40자 미만인 쪽만 JPEG 로 바꿔 AI에 보낸다.
- **AI**: Anthropic Claude API. 서버 함수(`/api/outline`, `/api/card`)에서만 호출하고 결과를 한 줄씩 흘려 보낸다(스트리밍). `/api/scene`(AI가 모션을 직접 짜는 방식)은 비교 실험용으로만 남겨 두었다. 구조화 출력(JSON 스키마)으로 형식을 고정하고, 프롬프트 캐시를 쓰며, Opus·Sonnet 은 거절·과부하 때 서버측 대체 모델(fallback)로 넘어간다.
- **소리**: Web Audio 로 효과음을 합성한다 (추가 비용 없음).
- **배포**: Vercel (Hobby, Fluid compute). 함수 하나는 최대 300초

**생성 흐름**

```
PDF·사진 ─ 브라우저: 글자 추출 · 쪽 미리보기 · 쪽 범위 고르기 · 그림 위주 쪽·스캔본은 그림으로
   │
   ▼
/api/outline  핵심 개념 뽑기 + 개념별 그림 판단 (긴 자료는 최대 4조각을 동시에 처리해 합침, 찾은 개념은 쓰는 중에 바로 보냄)
   │          코드 규칙: 숫자 없는 그래프 → 대신할 틀 · 같은 틀 3연속 → 다음 후보
   ▼
개념마다 카드 1장 (2장씩 동시에)
/api/card     그림 틀 칸 + 퀴즈 채우기 → 검사 → 문제와 이전 답을 붙여 한 번만 재시도 → 기본 카드
   │
   ▼
브라우저에 덱 저장 (같은 파일·범위·개수면 다시 만들지 않음)
   ├─ 텍스트 숏츠: 그림 + 개념 이름 + 정의 형광펜 (CSS 등장 효과)
   └─ 모션그래픽: 같은 카드로 시간표를 만들어 재생 (추가 AI 호출 없음)
```

lib/server/             Claude 호출, 프롬프트, 결과 검사·고치기, 그림 판단 규칙
lib/visual.ts           그림 틀 12종 계약 (UX/UI 디자인 스레드)
lib/assemble.ts         AI 결과 다듬기: 그림 판단 규칙, 카드 검사·고치기 (UX/UI 디자인 스레드)
lib/compileVisual.ts    카드 → 모션 시간표 (UX/UI 디자인 스레드)

**비용·안정성 원칙 (비용 관리 스레드에서 정함)**

- AI는 서버 함수에서만 호출하고, API 키는 Vercel 환경변수에만 둔다.
- 생성 결과는 브라우저에 저장해서 같은 자료·범위·개수면 다시 쓰고, 예시 덱은 코드에 미리 넣어 둔다 (API 장애 대비).
- DB 없이 시작하고, 로그인·공유가 필요해지면 Supabase Free를 쓴다.
- Vercel 함수 시간 한도 안에 끝나도록 카드를 한 장씩 따로 만들고, 입력 길이 상한, 스트리밍, 카드별 시간 예산(재시도 포함 170초)을 둔다.
- IP당 하루 AI 호출 수(기본 150회)와 max_tokens에 상한을 둔다.
- 모션은 AI를 더 부르지 않고 같은 카드를 코드로 움직인다. 시험 생성(카드 5장, 기본 모델·노력 중간)에서 카드 한 장은 텍스트가 약 27초·출력 약 500자, AI가 모션을 직접 짜면 약 44초·출력 약 2,000자였다.
- 효과음은 Web Audio 로 합성하고, 이미지·음성 생성 API는 쓰지 않는다.

### 로컬 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                  # http://localhost:3000
```

키가 없어도 맛보기 덱은 동작합니다. Vercel 에서는 프로젝트 설정 > Environment Variables 에 `ANTHROPIC_API_KEY` 를 넣습니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | 서버 환경변수에만 둔다 |
| `AI_MODEL` | `claude-opus-5-5` | `claude-sonnet-5-5` / `claude-haiku-5-5` 로 바꿔 비용 비교 |
| `AI_EFFORT` | `medium` | `low` / `medium` / `high`. 단계별로 `AI_EFFORT_OUTLINE`, `AI_EFFORT_TEXT`(카드), `AI_EFFORT_MOTION`(비교용 `/api/scene`) |
| `DAILY_LIMIT` | `150` | IP당 하루 AI 호출 수 (카드 1장 = 1회) |
| `AI_CARD_BUDGET_MS` | `170000` | 카드 한 장에 쓰는 최대 시간 (재시도 포함). 비교용 `/api/scene` 은 `AI_SCENE_BUDGET_MS` |
| `AI_DEADLINE_MS` | `200000` | 개념 뽑기에 쓰는 최대 시간 |
| `MOCK_AI` | 없음 | `1` 이면 AI 없이 고정 결과로 화면 흐름만 시험 (로컬 전용) |

키 없이 화면 흐름 점검 (Playwright 필요):

```bash
npm run build
MOCK_AI=1 npx next start -p 3100 &
npm run e2e -- http://localhost:3100 자료.pdf scripts/out text     # 모션 보기로 시작하려면 마지막을 motion 으로
```
